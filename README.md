# DI Bootcamp — Stage 2 (Data Science & Generative AI)

Solutions for the Developers Institute bootcamp: Python foundations, data analysis, machine learning, deep learning, NLP, LLMs, RAG, prompt engineering, MCP and agentic AI.

Each exercise lives in `WeekN/DayM/<Exercise>/`. Every Jupyter notebook in Weeks 8–18 is **fully executed** (outputs, charts and written analyses are saved), and opens directly in Google Colab from the links below. The links point to the `main` branch and are publicly accessible.

## Running the notebooks

- Open any 📓 link: Colab loads the notebook straight from GitHub. *Runtime → Run all* re-executes it. The first cell installs the dependencies.
- Notebooks that need a GPU (CNNs, BERT/LoRA fine-tuning) say so at the top and fall back to a smaller CPU configuration.
- Notebooks that can use an API key (Gemini, Pinecone, GitHub Models) read it from Colab secrets and have a documented keyless fallback, so they run end to end without any key.
